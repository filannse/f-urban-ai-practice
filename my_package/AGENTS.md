# AGENTS.md

## Обзор проекта
Это учебный шаблон (boilerplate) для создания Python-пакетов. 
Основной код находится в папке `my_package`.

## Настройка окружения
- Проект использует виртуальное окружение `.venv` (Python 3.12).
- Активация окружения (Windows): `.venv\Scripts\Activate.ps1`

## Основные команды
- Установка пакета и зависимостей для разработки: `make install-dev` 
  (или `pip install -e ".[dev]"`)
- Проверка работоспособности: `python -c "import my_package; print('Проект готов к работе')"`

## Структура
- `pyproject.toml` — метаданные проекта и зависимости.
- `Makefile` — команды для автоматизации.
