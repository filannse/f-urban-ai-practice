# Размещение школ: Нижневартовск

Интерактивное приложение для оценки размещения новых школ в жилых кварталах Нижневартовска. Работает на данных и модели практики 2, не изменяет исходные файлы практики 2.

## Что умеет приложение

- Показывает исходную обеспеченность школами и карту 99 жилых кварталов.
- Позволяет выбрать квартал для размещения в ручном сценарии, на карте или в таблице.
- Не показывает остальные зоны и не разрешает размещать в них школы; при этом суммарные показатели считаются по всем 540 расчётным кварталам города.
- Пересчитывает вместимость, дефицит, обеспеченность и изменение по каждому жилому кварталу.
- Показывает карту в трёх режимах: исходное состояние, сценарий, изменение обеспеченности.
- В режиме «Изменение» закрашивает только кварталы, где появились новые школы; соседние кварталы с перераспределением спроса показываются в таблице и подсказке без заливки.
- Выполняет автоматический перебор всех 99 жилых кварталов для заданной вместимости одной школы.
- Показывает прогресс перебора, все проверенные варианты и **все равнозначные лучшие результаты**.
- Позволяет применить лучший квартал и вручную проверить, что результат совпадает с автоподбором.
- Показывает таблицу с населением, вместимостью, обеспеченностью и дефицитом; по умолчанию сортирует кварталы по населению.
- Сохраняет сценарии в браузере (`localStorage`) и сравнивает их в таблице.
- Экспортирует показатели по жилым кварталам в CSV.
- Содержит готовые сценарии эксперимента A, B и C.

## Данные и метод

- Данные: `examples/data/nizhnevartovsk/results/blocks_indicators_drive.geojson`, `examples/data/nizhnevartovsk/matrices/accessibility_matrix_drive.parquet`, `examples/data/nizhnevartovsk/manifest.json`.
- В `school-placement/data/accessibility_matrix_drive.parquet` лежит резервная копия матрицы; она используется, если файл практики 2 недоступен.
- Город: Нижневартовск; 540 расчётных кварталов, из них 99 жилых.
- Размещение разрешено только в кварталах с `land_use = residential`.
- Промышленные, рекреационные и прочие зоны не отображаются на карте и в таблице и не участвуют в автоподборе.
- Остальные кварталы участвуют в расчёте доступности и суммарных показателей.
- Граф: автомобильный (`drive`).
- Метод: `blocksnet.analysis.provision.competitive_provision`.
- Параметры: `self_supply=True`, `max_depth=1`, норматив 120 мест на 1 000 жителей, порог доступности 15 минут.
- Недостижимые пары в матрице заменены штрафом 180 минут.
- Исходное состояние: население 338 105 чел., вместимость 10 500 мест, спрос 40 699 мест, дефицит 30 199 мест, обеспеченность 25,8%.
- При добавлении 600 мест в жилой квартал 436: дефицит 29 599 мест, сокращение 600 мест, обеспеченность 27,3%.
- Если обе копии матрицы отсутствуют, перезапустите `examples/blocksnet_nizhnevartovsk.ipynb` по инструкции практики 2 — ноутбук создаст `accessibility_matrix_drive.parquet`.

## Установка

Из корня репозитория, используя Python из `.venv`:

```powershell
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m pip install -r school-placement/requirements.txt
```

`requirements.txt` приложения добавляет только Flask; остальные зависимости (BlocksNet, GeoPandas, pandas, pyarrow, loguru) уже описаны в `pyproject.toml` проекта.

## Запуск

Из корня репозитория:

```powershell
.\.venv\Scripts\python.exe school-placement/app.py
```

Не закрывайте окно терминала. Первый запуск занимает около 6–10 секунд: дождитесь строки `Running on http://127.0.0.1:5000`, затем откройте `http://127.0.0.1:5000` в браузере.

Если venv активирован, можно использовать `python school-placement/app.py`. Если порт 5000 занят, остановите старый процесс Python или запустите приложение на другом порту, изменив последнюю строку `app.py`.

Сервер разработки Flask предназначен для локального запуска и проверки, а не для публикации в интернете.

## Как пользоваться

1. В ручном сценарии выберите жилой квартал; либо нажмите на квартал на карте или строку в таблице.
2. Укажите вместимость школы и нажмите «Добавить школу в выбранный квартал».
3. Нажмите «Рассчитать сценарий».
4. Переключите карту в режим «Изменение», чтобы увидеть кварталы с новыми школами; изменения в соседних кварталах смотрите в таблице и подсказке.
5. Для проверки автоподбора задайте вместимость и нажмите «Разместить автоматически».
6. Дождитесь завершения перебора: приложение покажет прогресс, таблицу всех 99 жилых вариантов и список всех лучших кварталов.
7. Нажмите на номер лучшего квартала, чтобы применить его как ручной сценарий.
8. Сохраните сценарий и сравните его с другими в таблице сравнения.
9. Скачайте CSV с показателями по жилым кварталам.

## Готовые сценарии эксперимента

- **A** — одна школа на 600 мест в центральном жилом квартале 436.
- **B** — две школы по 300 мест в жилых кварталах 233 и 255.
- **C** — одна школа на 600 мест в квартале 287, представителе 90 равнозначных лучших по результату автоподбора.

Все три сценария дают одинаковое сокращение суммарного дефицита — 600 мест. Различается пространственный эффект:

- A улучшает 1 квартал (436).
- B улучшает 2 квартала (233 и 255).
- C улучшает 1 квартал (287).
- Во всех сценариях число кварталов с дефицитом остаётся 240.

Подробный разбор: `EXPERIMENT.md`.

## Проверки

Полная проверка занимает около 80 секунд, потому что перебирает все 99 жилых кварталов:

```powershell
python school-placement/verify.py
```

Проверяются:

- совпадение исходного расчёта с практикой 2;
- доступность для размещения только жилых кварталов (`land_use = residential`);
- отсутствие промышленных, рекреационных и прочих зон в таблице, на карте и в автоподборе;
- отклонение попытки разместить школу в нежилом квартале;
- равенство пустого сценария исходному состоянию;
- эффект добавления 600 мест;
- возврат к исходному состоянию после сброса;
- наличие изменений только в жилых кварталах;
- перебор всех 99 жилых кварталов;
- наличие 90 равнозначных лучших с сокращением 600 мест;
- выбор квартала 287 первым при равенстве результата;
- совпадение ручного размещения в лучшем квартале с автоподбором;
- эксперименты A, B и C: 1, 2 и 1 улучшенный квартал соответственно.

Пересоздать отчёт эксперимента:

```powershell
python school-placement/experiment.py
```

Скрипт записывает `EXPERIMENT.md` и `experiment_results.json`.

## Ограничения

- Население и вместимость школ — расчётные оценки практики 2, а не официальная статистика.
- Размещение ограничено 99 жилыми кварталами; нежилые зоны участвуют только в расчёте доступности.
- Учитывается только автомобильная доступность; пешеходная и транспортная доступность не проверяются.
- Модель не оценивает стоимость строительства, земельный участок, собственность, санитарные зоны и строительную готовность.
- Критерий автоподбора — только суммарный дефицит; 90 жилых кварталов дают одинаковый результат. Это не ошибка, а свойство критерия.
- Автоподбор размещает одну школу; распределение нескольких школ требует отдельного сценария.
- Сохранённые сценарии хранят снимок показателей в `localStorage`; при загрузке сценарий пересчитывается заново.
- Результаты зависят от полноты OpenStreetMap и качества исходных данных о школах и населении.
